## 오늘 배운 것 — 스케일링

### 1. 왜 스케일링을 하나
- 특성들의 범위를 정규화한다.
- 스케일링을 하지 않으면 단위 차이 때문에 각 값의 영향력이 매우 불균형하게 적용된다.
- 스케일링을 통해 안정적인 학습을 하며, 인공 신경망에서도 스케일링은 중요하다.

### 2. 거리 기반 모델
- 거리 기반 모델이란 말 그대로 거리를 재고, 이를 통해 **유사도를 측정**하는 모델이다. (군집, KNN, SVM 등)
- 거리는 좌표공간에서의 거리, 즉 **두 벡터 간의 거리**를 뜻한다.
- **의사결정나무**는 거리 기반 모델이 아니기 때문에 스케일링의 영향을 덜 받는다. 값의 크기가 아니라 "어디서 나눌지"만 보기 때문이다.

### 3. 스케일러의 종류
스케일링의 종류가 다르기 때문에, 데이터에 따라 다양한 것이 쓰인다.

| 스케일러 | 변환 | 기억할 점 |
|---|---|---|
| 표준화 `StandardScaler` | 열마다 평균 0, 표준편차 1 | 표준정규분포 꼴이 되므로 결과가 곧 **Z-score**다 |
| Min-Max `MinMaxScaler` | 0 ~ 1 | 이상치에 취약 |
| Robust `RobustScaler` | 중앙값 0, IQR 1 | 이상치가 많을 때 |
| MaxAbs `MaxAbsScaler` | −1 ~ 1 | **0은 0으로, 부호도 그대로** 유지된다. 그래서 0이 많은 데이터(희소 행렬)에 쓴다 |
| 벡터 정규화 `Normalizer` | **각 행의 길이를 1로** | 벡터의 크기 = 원점으로부터의 거리 |

- 위의 넷은 **열(feature) 단위**, 벡터 정규화만 **행(sample) 단위**로 스케일링한다.

### 4. 평가 데이터에서는 새로 구하지 않는다

```python
scaler = StandardScaler()
x_train_s = scaler.fit_transform(x_train)   # 학습 데이터로 평균·표준편차를 구하고 변환
x_test_s  = scaler.transform(x_test)        # 평가 데이터는 그 기준으로 변환만
```

- 평가 데이터에 대해서는 평균, 표준편차 같은 것들을 새로 구하지 않는다.
- 평가 데이터로 기준을 구하면, 모델이 평가 데이터를 **미리 들여다보는** 셈이 된다. 사실은 답안지를 보고 시험을 치는 것과 같다.

## 오늘 배운 것 — EDA

### 1. EDA란
- **EDA(탐색적 데이터 분석)** : 본격적인 분석이나 모델링에 앞서, **데이터에 질문하며 이해하는 과정**
- 목적 : 데이터 이해, 패턴과 관계 발견, 품질 문제 발견, 가설 생성과 검증, 알맞은 분석 기법 선택
- 예 : 쏟아지는 데이터에서 의미를 찾아낸 세이버매트릭스 (영화 「머니볼」)

### 2. EDA의 순서

| 순서 | 질문 |
|---|---|
| 1. 구조와 의미 | 한 행은 무엇을 의미하는가? 각 열은 무엇을 측정했는가? |
| 2. 품질 | 누락, 중복, 잘못 기록된 값이 있는가? |
| 3. 분포 | 값이 어디에 몰려 있고, 얼마나 흩어져 있는가? |
| 4. 이상치 | 보통과 크게 다른 관측치는 무엇인가? |
| 5. 관계 | 어떤 변수들이 함께 변하는가? |
| 6. 집단 비교 | 전체에서는 안 보이던 집단별 차이가 있는가? |
| 7. 시간 변화 | 추세, 계절성, 갑작스러운 변화가 있는가? |
| 8. 정리 | 무엇을 알게 되었고, 무엇을 더 확인해야 하는가? |

- 예 : 고객 이탈 데이터라면, 접속 기록이 없는 것은 **미접속인가, 수집 누락인가?**

### 3. 단변량 분석 — 변수 하나의 특성 파악

| 변수 | 숫자로 보기 | 그래프로 보기 |
|---|---|---|
| 수치형 | 평균, 중앙값, 최빈값, 분산, 표준편차, 사분위수 | 히스토그램, 박스플롯, 바이올린 플롯, Q-Q 플롯 |
| 범주형 | 범주별 빈도, 구성 비율 | 막대그래프 |

- 수치형에서 볼 것 : 값의 범위, 치우친 방향, 이상치, 결측치
- **Q-Q 플롯** : 이론적인 정규분포의 분위수와 실제 데이터의 분위수를 비교해, 데이터가 정규분포를 따르는지 확인한다. 점이 기준선 근처에 놓이면 정규분포에 가깝다.

```python
sns.violinplot(x=df["age"])   # 바이올린 플롯 : 박스플롯 + 분포 모양
```
