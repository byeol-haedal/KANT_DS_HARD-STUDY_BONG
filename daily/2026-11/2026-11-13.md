## 오늘 배운 것 — 샘플링

- **샘플링** : 모집단에서 조사·분석할 일부를 골라 표본을 만드는 과정. 모집단을 추론하려면 표본의 **대표성**을 고려해야 한다.
- 왜 하나? 시간과 비용의 제약, 큰 데이터의 분석 효율, 불필요한 노이즈 제거

| 종류 | 방법 | 예 |
|---|---|---|
| 단순 무작위 | 모든 개체를 같은 확률로 뽑는다 | 기본 방법 |
| 계통 | 첫 표본만 무작위, 이후 일정 간격 | 조립 라인에서 매시간 제품 검사 (주기와 간격이 겹치면 위험) |
| 층화 | 비슷한 특성끼리 층을 나눈 뒤 층마다 무작위 | 연령대별, 성별 조사 |
| 군집 | 군집을 나눠 일부 군집을 통째로 조사 | 서울시 가구 조사 |

- **비확률 샘플링** : 편의, 판단, 눈덩이 샘플링. 빠르고 쉽지만 대표성을 확신하기 어렵다.
- **부트스트랩** : 관측한 표본에서 **복원 추출**을 반복해 여러 재표본을 만들고, 통계량이 얼마나 달라지는지 본다. 배깅(Bagging)의 바탕이다.
  - 복원 추출 = 뽑은 걸 다시 넣는다 (중복 가능) / 비복원 추출 = 다시 넣지 않는다
- 재현성을 위해 샘플링에 **시드값을 고정**하고 과정을 기록한다.

> **빅데이터 시대에도 샘플링은 필요하다.** 표본이 커지면 무작위 오차는 줄지만, 잘못된 수집 방식에서 생긴 **편향은 자동으로 사라지지 않는다.**

## 오늘 배운 것 — 스케일링

- **스케일링** : 특성마다 다른 값의 범위를 일정한 기준에 맞게 조정하는 전처리
- 왜 하나? 연봉(수천만)의 1이 키(cm)의 1보다 중요한 게 아니다. 단위 차이가 결과를 좌우하지 않게 한다. 특히 거리 기반 모델(군집, KNN, SVM)에서 중요하다.
  - 수학 100점 만점 + 학점 4.5점 만점을 그대로 더하면 수학 점수만 의미 있어진다.

| 종류 | 변환 | 언제 |
|---|---|---|
| 표준화 (`StandardScaler`) | 평균 0, 표준편차 1 (Z-점수) | 대부분의 기본값. 선형 모델, SVM, 신경망 |
| Min-Max (`MinMaxScaler`) | 0 ~ 1 | 범위를 고정하고 싶을 때, 이미지 픽셀. 이상치에 취약 |
| Robust (`RobustScaler`) | 중앙값 0, IQR 1 | 이상치가 많을 때 |
| MaxAbs (`MaxAbsScaler`) | −1 ~ 1, 0과 부호 유지 | 0이 많은 희소 데이터 |
| 벡터 정규화 (`Normalizer`) | 각 **행**의 길이를 1로 | 텍스트, 코사인 유사도 |

- 앞의 넷은 **열(feature) 단위**, 벡터 정규화만 **행(sample) 단위**로 스케일링한다.

```python
mms = MinMaxScaler()
x_train_s = mms.fit_transform(x_train)   # 학습 데이터로 기준을 정하고 변환
x_test_s = mms.transform(x_test)         # 테스트 데이터는 그 기준으로 변환만
```
