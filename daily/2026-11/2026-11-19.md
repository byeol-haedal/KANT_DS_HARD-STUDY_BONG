## 오늘 배운 것

### 1. 회귀(Regression)라는 이름
- 라틴어 *regressio* = re-(뒤로, 다시) + *gradī*(걷다) → **"다시 돌아감"**
- 19세기 말 프랜시스 골턴이 부모와 자식의 키를 연구하다가 발견했다.
  - 키가 매우 큰 부모의 자녀는 부모보다 다소 작고, 매우 작은 부모의 자녀는 다소 크다.
  - 값이 평균 쪽으로 되돌아가는 경향 → **평균으로의 회귀(regression toward the mean)**

| 구분 | 뜻 |
|---|---|
| 평균으로의 회귀 (통계 현상) | 극단적인 값을 보인 집단이 다시 측정하면 평균에 더 가까운 값을 보이는 경향 |
| 회귀분석 (통계 방법) | 설명변수와 종속변수의 관계를 모형화해 해석하거나 예측하는 통계 모델 |
| ML의 회귀 (Task) | 입력 변수의 정보로 **수치형 목표값을 예측**하는 과제 |

<br>

### 2. KNN (K-Nearest Neighbors, K-최근접 이웃)
- 새 데이터가 들어오면 **가장 가까운 K개의 기존 데이터**를 보고, 그중 다수인 범주로 분류한다.
- **K** : 판단에 쓰는 가까운 이웃의 개수. 같은 새 데이터라도 K에 따라 결과가 달라진다. (슬라이드 예시 : K=1이면 cluster 3, K=4면 cluster 1, K=6이면 cluster 2)
- 추론 과정
  1. **거리 계산** : 새 데이터와 모든 훈련 데이터 사이의 거리를 잰다.
  2. **이웃 선택** : 가장 가까운 K개를 고른다.
  3. **예측** : 분류는 다수결, 회귀는 평균

#### 거리 계산 방법

| | 유클리드 거리 | 맨해튼 거리 |
|---|---|---|
| 뜻 | 두 점을 **직선(대각선)으로** 이은 길이 | 가로·세로로만 움직인 **이동 거리의 합** |
| 공식 | √((q₁−p₁)² + (q₂−p₂)² + …) | \|q₁−p₁\| + \|q₂−p₂\| + … |
| P(1, 2) → Q(4, 6) | √(3² + 4²) = **5** | 3 + 4 = **7** |
| 비유 | 하늘을 나는 새 | 바둑판 같은 도시의 길을 걷는 사람 |

- 맨해튼 거리는 길을 어떻게 돌아가든(빨강, 파랑, 노랑) 가로·세로 이동량이 같으면 길이가 같다.
- **어떤 거리를 쓰느냐에 따라 "비슷한 고객"이 달라진다.** 기준 고객이 상품 A, B, C를 10개씩 샀을 때

| 고객 | 구매 수량 (A, B, C) | 차이 | 맨해튼 | 유클리드 |
|---|---|---|---|---|
| P | 10, 10, 16 | 0, 0, 6 | **6** (더 가깝다) | 6 |
| Q | 13, 13, 13 | 3, 3, 3 | 9 | **5.20** (더 가깝다) |

- 맨해튼은 총 구매량 차이가 작은 P를, 유클리드는 한 상품에서 크게 튀지 않는 Q를 더 비슷하다고 본다. 유클리드는 차이를 제곱하기 때문에 큰 차이 하나에 더 민감하다.

#### KNN은 "게으른 학습(lazy learning)"
- `knn.fit(X_train, y_train)`은 사실상 훈련 데이터를 저장해 둘 뿐이다.
- 테스트 데이터가 들어오면 **그때** 거리를 계산하기 때문에 게으른 학습이라고 부른다.
- K값 정하기 : 경험적으로 **√N** (N은 전체 데이터 수)에서 시작해 K를 바꿔 가며 성능을 확인한다.
- 거리를 재는 모델이므로 **스케일링이 중요하다.** (11/16 스케일링에서 배운 거리 기반 모델)

### 3. 의사결정나무 (Decision Tree)
- 특정 기준(질문)에 따라 데이터를 나누는 모델. 한 번 분기할 때마다 영역을 **두 개로** 나눈다.
- 무엇으로 나눌까? **정보 이득이 큰 방향으로** 노드를 분할한다.

| 용어 | 뜻 |
|---|---|
| 엔트로피 | 데이터의 무질서도·불확실성. 클수록 섞여 있고, 0이면 한 종류만 있는 순수한 상태 |
| 정보 이득 | 분할 후 엔트로피가 얼마나 줄었는가 = 분할 전 엔트로피 − 분할 후 엔트로피(크기 비율로 가중 평균) |

```
엔트로피 = − Σ pᵢ · log₂(pᵢ)

예) 14개 중 9개는 클래스 1, 5개는 클래스 0
    − (9/14)·log₂(9/14) − (5/14)·log₂(5/14) ≈ 0.940

예) T T F F F 를 "비늘 유무"로 나누면 → [T T F] 와 [F F]
    분할 전 : − (2/5)·log₂(2/5) − (3/5)·log₂(3/5) ≈ 0.971
    분할 후 : (3/5) × 0.918 + (2/5) × 0 ≈ 0.551
    정보 이득 ≈ 0.971 − 0.551 = 0.420
```

- 정보 이득이 큰 특성일수록 유용한 정보를 준다고 보고 먼저 고른다. 아이리스에서는 **petal length**의 중요도(0.89)가 압도적으로 컸다.

#### 하이퍼파라미터 확인하기

```python
clf = DecisionTreeClassifier(random_state=42)
clf.get_params()               # 기본 설정값 확인
help(DecisionTreeClassifier)   # 옵션 설명 확인
```

| 파라미터 | 기본값 | 뜻 |
|---|---|---|
| `criterion` | `'gini'` | 분할 기준(불순도). `'entropy'`로 바꾸면 정보 이득 사용 |
| `max_depth` | `None` | 끝까지 분할한다 → **과적합 위험** |
| `min_samples_split` | 2 | 분할하려면 최소 몇 개가 있어야 하는가 |
| `min_samples_leaf` | 1 | 리프 노드에 최소 몇 개가 남아야 하는가 |
| `max_features` | `None` | 모든 특성 사용 |
| `splitter` | `'best'` | 가장 좋은 분할 선택 |

- 지니 계수는 로그 계산이 없어 빠르면서, 엔트로피와 비슷한 분류 성능을 낸다.
- 트리의 규칙은 글로도 볼 수 있다 : `export_text(clf, feature_names=iris.feature_names)`

#### 분류 트리 vs 회귀 트리

| | 분류 `DecisionTreeClassifier` | 회귀 `DecisionTreeRegressor` |
|---|---|---|
| 분할 기준 | 불순도(지니, 엔트로피)를 줄인다 | **MSE(평균제곱오차)** 를 줄인다 |
| 목표 | 같은 클래스끼리 모인 하위 그룹 | 비슷한 정답값끼리 모인 하위 그룹 |
| 리프의 예측 | **다수결** (가장 많은 클래스) | **평균** (또는 중앙값) |
| 예 | 이메일 스팸 구분 | 크기·위치로 주택 가격 예측 |

- 공통점 : 트리 구조, 재귀적 이진 분할, `max_depth`·`min_samples_split`·`min_samples_leaf`로 성장을 멈춰 과적합을 막는다.
- 회귀 트리 노드 읽기 : `Feature 1 <= 0.094`(분할 질문), `squared_error`(노드 안의 MSE, 작을수록 순수), `samples`(노드의 데이터 수), `value`(노드의 예측값 = 정답의 평균)

### 4. 랜덤 포레스트 (Random Forest)
- 나무(Tree)가 모여 숲(Forest)을 이룬다. **여러 개의 결정 트리**를 모은 모델이다.
- 왜? 결정 트리 하나는 훈련 데이터에 **오버피팅되는 경향**이 있다.
- 방법 : 특성을 무작위로 골라 작은 트리를 여러 개 만들고, 각 트리의 예측을 모은다.
  - 분류는 **다수결**, 회귀는 **평균** → 이렇게 여러 결과를 합치는 방식이 **앙상블**이다.
  - 트리마다 조금씩 다르게 학습해서, 개별 트리의 오차가 서로 상쇄된다.

```python
rf_clf = RandomForestClassifier(n_estimators=100, random_state=42)  # 트리 100개
rf_clf.fit(X_train, y_train)
rf_clf.feature_importances_   # 특성 중요도
```

- `n_estimators` : 숲 안의 트리 개수 / `max_features` : 무작위로 고를 특성의 개수

### 5. 과적합과 일반화

| | 뜻 |
|---|---|
| 언더피팅 | 학습 데이터의 특성을 제대로 잡지 못한 상태 |
| 오버피팅 | 학습 데이터의 노이즈와 세부 패턴까지 외워서, 새로운 데이터에서 성능이 크게 떨어지는 상태 |
| 일반화 | 경험하지 않은 새로운 데이터에서도 잘 예측하는 능력 |

- 언더피팅과 오버피팅 사이에서 적절히 학습시켜야 한다. 둘은 **트레이드오프** 관계다.
