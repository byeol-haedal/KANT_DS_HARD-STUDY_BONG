## 오늘 배운 것

### 1. EDA와 시각화의 목적
- **EDA(탐색적 데이터 분석)** 는 데이터가 어떤 내용인지 들여다보는 것. 똑똑한 피처(feature)를 골라낸다.
- 이미지는 그래프로(산포도를 많이 쓴다), 숫자는 수치 통계량으로 본다.
- 데이터 시각화는 우리가 말하려는 바, 혹은 데이터 안에서 찾은 통찰을 **이해하기 쉬운 방식으로 전달**하기 위해 하는 것이다.
- 따라서 데이터 시각화는 **독자가 이해하기 쉽게** 만들어져야 한다.

| 구분 | 설명 방법 |
|---|---|
| 양적 데이터 (정량적, 수치형) | 기초 통계량 |
| 질적 데이터 (정성적, 범주형) | 범주별 빈도수, 범주별 비율 |

### 2. 시각화의 중립성
- 데이터를 봐야 하는데, 내 의지가 담기거나 담고 싶어질 때가 있다.
- 조금만 의지가 반영되어도 메시지에 의도성이 담길 수 있으니 **중립성을 잘 지켜야 한다.** 선은 좀 지키자.
- 시각화의 함정 : 축을 자를 때는 물결 표시를 사용하는 것도 방법이다.

### 3. Matplotlib
- 대표적인 시각화 라이브러리. 좀 더 범용적이다. 시각화한 이미지는 나중에 저장할 수 있다.
- 옵션이 아주 많지만, 그 옵션을 다 모른다고 불안해하지 마라. 자동차 매뉴얼을 다 알아야 운전할 수 있는 건 아니다.
- 마커 옵션 : `ms` = marker size / `mec` = marker edge color / `mfc` = marker face color
- **subplot** : 한 화면에 그래프를 여러 개 그린다.
  - rows(행) : 세로 칸 수 (2 → 위아래 두 개)
  - columns(열) : 가로 칸 수 (2 → 좌우 두 개)
  - index : 몇 번째 칸에 그릴지. 왼쪽 위에서 오른쪽으로, 그다음 아래로 이어진다. (1부터 시작)
- 그리드로 변수 간 관계를 볼 수 있다. 단, 그리드가 너무 진하면 본질을 가린다.

### 4. 어떤 그래프를 고를까

| 그래프 | 언제 쓰나 |
|---|---|
| 선 그래프 | 시간 흐름에 따른 변화 (분기별 매출, GDP 등) |
| 막대 그래프 | 항목 간 비교 (범주형 데이터) |
| 히스토그램 | 연속형 수치 데이터의 분포 |
| 산포도(Scatter plot) | 두 변수 간의 관계 |
| 박스플롯 | 중앙값, 사분위수, 이상치 |

### 5. 도수분포표와 히스토그램
- **도수분포표** : 수치 데이터를 몇 개의 구간으로 나누고, 각 구간에 속한 데이터 개수(도수)를 세어 정리한 표
  - 구간이 겹치지 않도록 주의한다. (이상, 미만을 잘 쓰자)
- **히스토그램** = 도수분포표를 그래프로 만든 것. 빈도수가 많은 곳을 시각적으로 바로 확인할 수 있다.
- **빈(bin)** : 데이터 범위를 여러 구간으로 나눈 것
  - 빈이 조밀할수록 안 보이던 것이 보이고, 읽을 수 있는 것이 많아진다.
  - 그렇다고 무조건 조밀하게 하면 경향성을 보기 힘들어질 위험이 있다.

### 6. 산포도
- 두 변수 간의 관계를 시각적으로 표현한 그래프
- 머신러닝에서 x는 설명변수, y는 정답(타깃)
  - 아이리스라면 x는 꽃받침과 꽃잎의 가로·세로 길이 네 가지, y는 꽃 종류

### 7. 사분위수, IQR, 박스플롯
- **사분위수** : 데이터를 크기순으로 줄 세운 뒤, 반을 자르고, 그 반을 다시 반으로 자른 지점. Q1, Q2(중앙값), Q3
- **IQR** = Q3 − Q1. 데이터 중간 50%가 분포하는 범위. 퍼짐의 정도를 알 수 있다.
- 박스플롯에서 상자는 Q1~Q3, 상자 안의 선이 Q2(중앙값)다.
- 상자 밖으로 뻗은 선을 **수염(whisker)** 이라고 하고, 수염 밖에 있는 점이 **이상치**다.

```
이상치 경계 = Q1 − 1.5 × IQR  ~  Q3 + 1.5 × IQR

예) Q1 = 21, Q3 = 35
    IQR = 35 − 21 = 14
    아래 경계 = 21 − 1.5 × 14 = 0
    위 경계   = 35 + 1.5 × 14 = 56
    → 0 ~ 56을 벗어나면 이상치
```

- 경계를 벗어나는 값이 많으면 극단적인 값이 많은 것이고, 적으면 중앙에 많이 분포한 것이다.
- 명확한 데이터군과 이상치가 많은 데이터군이 눈에 띈다.
- **똘똘한 지표는 모델링까지 들고 가야 한다.**
