## 주제
**기초통계 — 공분산, 상관, 회귀**

<br>

## 오늘 배운 것

### 1. 분산 → 공분산 → 상관 → 회귀

| 구분 | 묻는 것 |
|---|---|
| 분산 | 하나의 변수는 얼마나 퍼져 있는가? |
| 공분산 / 상관 | 두 변수는 어떤 방향으로 얼마나 함께 변하는가? |
| 회귀 | 그 관계를 식으로 표현해 Y를 예측할 수 있는가? |

### 2. 공분산의 한계와 상관계수
- **공분산** : 두 변수가 함께 변하는 정도. 단, 단위에 따라 값이 달라진다.
  - 키를 m에서 cm로 바꾸면 공분산이 100배가 되지만, 관계가 강해진 것은 아니다.
- **피어슨 상관계수(r)** : 공분산을 두 변수의 표준편차의 곱으로 나눠 단위의 영향을 없앤 것. −1 ~ 1
  - 위 예시에서 m이든 cm든 상관계수는 0.982로 같다.

### 3. 상관계수의 종류

| 종류 | 무엇을 보나 |
|---|---|
| 피어슨 | 두 수치형 변수의 **선형** 관계. 이상치에 민감 |
| 스피어만 | 값의 **순위**로 본 단조 관계 (꾸준히 커지거나 꾸준히 작아지는 관계) |
| 켄달 | 관측값 쌍의 순서가 일치하는 정도. 표본이 작거나 동점이 많을 때 |

- 해석 기준(예시) : |r| 0.7 이상 강함, 0.3~0.7 뚜렷함, 0.1~0.3 약함, 0.1 미만 거의 없음. **분야와 목적에 따라 달라진다.**
- Y = X² 처럼 관계가 뚜렷해도 직선이 아니면 피어슨 상관계수는 0에 가깝게 나온다. **상관계수 0은 "관계 없음"이 아니라 "선형 관계 없음"이다.**

### 4. 상관분석 vs 회귀분석

| 구분 | 상관분석 | 회귀분석 |
|---|---|---|
| 묻는 것 | 얼마나 함께 변하는가? | X가 주어지면 Y를 어떻게 예측하는가? |
| 변수 | X와 Y를 바꿔도 같음 | 설명변수 X와 목표변수 Y를 구분 |
| 결과 | 상관계수 | 회귀식, 계수, 예측값 |

- 둘 다 **인과관계를 입증하지 못한다.**
- **회귀계수 2.0** : 공부 시간이 1시간 늘면 시험 점수가 평균적으로 2점 오른다.
- **결정계수 R²** : 모형이 Y의 변화를 얼마나 설명하는지 (0~1). R² = 0.5면 50%를 설명한다.
  - 좋은 R²의 기준은 분야마다 다르다. (예 : 바이오 0.95, 공학 0.7, 사회과학 0.3)

### 5. 선형과 비선형
- 선형 : 직선, `y = mx + b` / 비선형 : 곡선
- 신경망에 선형 활성화 함수만 쓰면, 층을 아무리 쌓아도 결국 하나의 선형 함수가 된다. 그래서 **비선형 활성화 함수**가 필요하다.
