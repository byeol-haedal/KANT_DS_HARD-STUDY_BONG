## 오늘 배운 것 — Apriori

### 1. Apriori란
- 대규모 데이터에서 **자주 함께 등장하는 항목 집합(빈발 항목집합, frequent itemsets)** 을 찾고, 이를 바탕으로 연관 규칙을 만드는 알고리즘
- 어제 배운 **탐색 공간** 문제(항목 N개 → 조합 2ᴺ − 1개)를 줄이기 위한 방법이다.
- 핵심 원리 : **부분집합이 자주 등장하지 않으면, 그것을 포함한 더 큰 집합도 자주 등장할 수 없다.**
  - 예 : {A, B}가 드물다면 {A, B, C}, {A, B, D}, {A, B, C, D, E}도 드물다. A와 B를 함께 산 거래보다 A, B, C를 모두 산 거래가 더 많을 수는 없기 때문이다.
  - 그래서 {A, B}가 드물다고 확인되는 순간, 그 위의 큰 집합들은 **계산하지 않고 통째로 잘라낸다(가지치기, pruning).**

### 2. Apriori의 과정
1. 항목 1개짜리 집합의 지지도를 계산하고, **최소 지지도**를 넘는 것만 남긴다.
2. 남은 항목으로 2개짜리 집합을 만들고 지지도를 계산한다.
3. 지지도가 낮은 집합은 버리고, 남은 집합으로 3개짜리 집합을 만든다.
4. 더 이상 최소 지지도를 넘는 집합이 없을 때까지 반복한다.
5. 찾은 빈발 항목집합으로 **연관 규칙을 만들고 신뢰도를 계산**한다.

- 1개 → 2개 → 3개로 **크기를 한 단계씩 키우면서**, 매 단계마다 드문 것을 걸러낸다.

## 오늘 배운 것 — 차원과 특성 설계

### 1. 차원이란
- ML에서 **차원 = 데이터 하나를 표현하는 입력 특성의 개수**

| 집값 예측에 쓰는 특성 | 차원 |
|---|---|
| 면적 | 1차원 |
| 면적, 방 개수 | 2차원 |
| 면적, 방 개수, 건축 연도 | 3차원 |
| 위 특성 + 역까지의 거리 | 4차원 |

- 1,000행 × 10열 데이터라면 샘플 수는 1,000개, 차원은 10이다. **샘플이 늘어나는 것과 차원이 늘어나는 것은 다르다.**
- 차원이 늘어나는 경우
  - 새로운 정보 추가 : 집값 예측에 "역까지의 거리"
  - 파생변수 추가 : 기존 x에 x² 추가
  - 범주형 변환 : 원-핫 인코딩으로 범주마다 열이 생김 (11/17)

### 2. 차원의 저주 (Curse of Dimensionality)
- 차원이 늘면 저장 공간과 계산량이 늘어난다.
- 더 큰 문제는 **데이터가 공간에 듬성듬성 흩어진다**는 것이다. 차원이 하나 늘 때마다 공간은 기하급수적으로 넓어지는데 데이터 수는 그대로라서, 같은 양의 데이터로는 공간을 채울 수 없다.
- 그러면 모든 점 사이의 거리가 비슷비슷해져서 **"가깝다"는 말의 의미가 약해진다.** 거리를 재는 KNN, K-Means가 특히 영향을 받는다.

### 3. 변수를 늘릴 때 따질 것

| 변수 추가 사례 | 판단 |
|---|---|
| 집값 예측에 "역까지 거리" 추가 | 집값과 관련된 중요한 정보를 줄 수 있다 |
| "면적(m²)"에 "면적(ft²)" 추가 | 단위만 바뀐 같은 정보라 이득이 적다 |
| 기존 x에 x² 추가 | 선형 모델이 곡선 관계를 표현하도록 돕는다 (11/23 다항 회귀) |
| 관련 없는 임의의 숫자 추가 | 정보 없이 계산과 과적합 부담만 늘린다 |

- 세 가지 기준
  - **효과** : 검증 데이터에서 예측 성능이 좋아지는가?
  - **안정성** : 훈련 성능만 좋아지거나, 특정 데이터에서만 효과가 나는 건 아닌가?
  - **비용** : 학습·예측 시간과 메모리가 얼마나 늘어나는가?
- **실제 예측 시점에도 쓸 수 있는 변수인가**도 확인해야 한다. 예측할 때는 알 수 없는 값을 학습에 쓰면 데이터 누수가 된다.
- 목표는 변수를 최대로 늘리거나 최소로 줄이는 게 아니라, **유용한 정보를 적절한 비용으로** 쓰는 것이다. 실험에서는 변수를 적극적으로 만들어 보되, 최종 모델에 남길지는 검증으로 정한다.

### 4. 차원을 줄이는 방법

| 방법 | 설명 | 예 |
|---|---|---|
| 특성 선택 | 기존 특성 중 필요한 것만 고른다 | 중복되거나 예측에 도움이 적은 특성 제거 |
| 특성 추출 | 여러 특성을 조합해 더 적은 수의 **새 특성**을 만든다 | PCA |
| 파생변수 범위 제한 | 모든 조합을 만들지 않고 필요한 변환만 만든다 | 모든 제곱항 대신 필요한 항만 |

- 특성 선택은 원래 특성을 **그대로 남기고**, 특성 추출은 원래 특성을 **섞어서 새 축을** 만든다.

## 오늘 배운 것 — PCA

### 1. PCA (Principal Component Analysis, 주성분 분석)
- 데이터의 변동(분산)을 가능한 한 많이 보존하면서, 여러 특성을 **더 적은 수의 새로운 특성(주성분)** 으로 표현하는 방법
- 예 : 국어 점수와 영어 점수가 함께 높아지는 경향이 있으면, 두 점수를 조합한 **하나의 축**으로 학생들의 전반적인 점수 차이를 상당 부분 표현할 수 있다. (2차원 → 1차원)
- 비유 : 용수철이 움직이는 모습을 기록할 때, 카메라를 **용수철이 가장 크게 움직이는 방향**에 맞춰 놓으면 한 대로도 움직임을 거의 다 담을 수 있다.

### 2. 주성분을 찾는 방법
- **첫 번째 주성분(PC1)** = 데이터가 **가장 넓게 퍼져 있는(분산이 가장 큰) 방향**
- **두 번째 주성분(PC2)** = PC1과 **직각**이면서, 남은 분산이 가장 큰 방향
- 이런 식으로 주성분을 구한 뒤, 앞쪽 몇 개만 남기고 나머지(분산이 작은 방향)를 버리면 차원이 줄어든다.
- PCA는 **정답(y)을 보지 않는 비지도 기법**이다. 데이터가 퍼진 방향만 보고 축을 정한다.

### 3. 설명된 분산 비율 (Explained Variance Ratio)
- 실습(아이리스) 결과 : PC1 = **0.7296**, PC2 = **0.2285**
  - PC1 하나가 전체 변동의 약 73%를, PC2가 약 23%를 설명한다.
  - 두 개를 합치면 약 **96%** → 4차원 데이터를 2차원으로 줄여도 변동의 대부분이 남는다.
- 몇 개의 주성분을 남길지 정할 때 이 비율의 누적 합을 기준으로 삼는다. (예 : 누적 90~95%)

```python
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X_scaled = StandardScaler().fit_transform(X)   # PCA 전에 스케일링
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
pca.explained_variance_ratio_                   # 각 주성분이 설명하는 분산 비율
```

- **PCA 전에는 스케일링을 해야 한다.** PCA는 분산이 큰 방향을 찾기 때문에, 단위가 큰 특성(예 : 연봉)이 있으면 그 특성의 방향이 PC1을 차지해 버린다. (11/16 스케일링)

### 4. PCA의 역할

| 역할 | 의미 |
|---|---|
| 정보 압축 | 여러 특성에 흩어진 변동을 적은 수의 주성분으로 요약 |
| 중복 완화 | 함께 변하는 특성들의 정보를 하나로 조합 |
| 계산 부담 감소 | 모델에 넣는 특성 수를 줄임 |
| 시각화 | 고차원 데이터를 2~3개 주성분으로 그림 |
| 잡음 감소 가능성 | 버린 방향에 잡음이 많았다면 일반화 성능이 좋아질 수 있음 |
| 이상치 탐지 | 주성분으로 잘 설명되지 않는, 대부분의 데이터와 동떨어진 점을 찾음 |

- 실습에서는 PCA로 대부분의 데이터가 모인 무리에서 멀리 떨어진 점들을 이상치로 표시했다.
- **특성 추가**는 모델이 쓸 표현을 풍부하게 만드는 과정이고, **PCA**는 여러 특성의 변동을 적은 축으로 압축하는 과정이다.
- 주성분은 원래 특성들을 섞은 값이라 **"PC1이 무엇을 뜻하는가"를 해석하기 어렵다.** 압축의 이득과 해석·정보 손실 사이에서 균형을 찾아야 한다.
