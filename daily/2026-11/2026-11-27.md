## 오늘 배운 것 — 앙상블

### 1. 앙상블이란
- 사전적 의미 : 2인 이상이 함께 하는 노래나 연주, 소인원 합주단
- ML에서는 **여러 개의 기본 학습기(Base Learner)의 예측을 결합**해, 하나의 모델보다 더 좋은 성능과 안정성을 얻는 기법
- **약한 학습기(Weak Learner)** : 혼자서는 패턴을 완벽하게 학습하지 못하지만(무작위로 찍는 것보다 조금 나은 정도), 여럿을 조합하면 강한 성능을 낼 수 있는 모델
  - 기본 학습기가 늘 약한 학습기인 것은 아니다. 부스팅은 약한 학습기를 쓰지만, 랜덤 포레스트는 깊게 자란 트리를, 스태킹은 각각 성능이 좋은 모델을 쓴다.

### 2. 다양성 (Diversity) — 앙상블이 효과를 내는 조건
- 각 모델이 **기준선(Base Line)보다는 나은 성능**을 내야 한다.
- 그리고 **서로 다른 방식으로 틀려야** 한다. 모두 같은 곳에서 틀리면 합쳐도 고쳐지지 않는다.

| 다양성을 만드는 방법 | 예 |
|---|---|
| 학습 데이터와 샘플 가중치 바꾸기 | 부트스트랩, 서브샘플링, AdaBoost의 샘플 가중치 |
| 입력 특성 바꾸기 | 랜덤 포레스트의 무작위 특성 선택 |
| 학습 과정에 무작위성 넣기 | 신경망의 서로 다른 초기 가중치, 데이터 셔플 (단, 성능이 꼭 좋아지는 것은 아니다) |
| 모델 종류·구조·하이퍼파라미터 바꾸기 | 로지스틱 회귀 + SVM + 결정 트리 + KNN, 트리 깊이를 다르게 |

### 3. 배깅, 부스팅, 스태킹

| | 배깅 (Bagging) | 부스팅 (Boosting) | 스태킹 (Stacking) |
|---|---|---|---|
| 이름 | Bootstrap + Aggregating | Boost : 강화하다 | Stack : 쌓다 |
| 다양성 | 서로 다르게 뽑은 데이터 | 앞 모델이 부족한 부분을 보완 | 서로 다른 종류의 모델 |
| 학습 | **병렬** (동시에 따로) | **순차** (앞 모델 다음에) | 기본 모델 → 메타 모델 |
| 결합 | 평균(회귀), 다수결·확률 평균(분류) | 가중합, 가중 투표 | 메타 모델이 결합 방법을 학습 |
| 주로 줄이는 것 | **분산** | **편향** | |
| 예 | 랜덤 포레스트 | AdaBoost, GBM, XGBoost, LightGBM | `StackingClassifier` |

#### 배깅이 분산을 줄이는 예
- 서로 다른 데이터로 학습한 5개 모델이 같은 입력에 대해 20, 80, 45, 65, 30을 예측했다면 평균은 **48**
- 지나치게 크거나 작은 예측이 평균으로 완화된다. 모델들의 오류가 완전히 같지 않다면, 평균은 데이터가 조금 바뀌어도 덜 흔들린다.

#### 부스팅이 편향을 줄이는 예
- 다음 모델은 원래 정답(50, 80, 30) 대신 **남은 오차(잔차)** 를 맞히도록 학습한다.

| 입력 | 정답 | 기존 예측 | 남은 오차 | 다음 모델의 보정값 | 합친 예측 |
|---|---|---|---|---|---|
| A | 50 | 40 | +10 | +8 | 48 |
| B | 80 | 60 | +20 | +15 | 75 |
| C | 30 | 35 | −5 | −4 | 31 |

- 기존 모델이 낮게 또는 높게 예측한 부분을 보정값으로 고쳐 나간다. 단순한 모델이 놓친 패턴을 채운다.

```python
bagging_clf = BaggingClassifier(
    estimator=DecisionTreeClassifier(),
    n_estimators=100,      # 모델 100개
    bootstrap=True,        # 복원 추출
    random_state=42
)
bagging_clf.fit(X_train, y_train)
bagging_clf.score(X_test, y_test)
```

## 오늘 배운 것 — 배깅

### 1. 부트스트랩 (11/13 샘플링)
- 원본 데이터에서 **복원 추출**로 n개를 뽑아 표본 하나를 만들고, 이를 R번 반복한다.
- 한 샘플이 여러 번 뽑히기도 하고, 한 번도 안 뽑히기도 한다.
- 원래는 통계량이 얼마나 흔들리는지 추정하는 재표집 기법이다. 배깅은 이 표본들로 **각각 모델을 학습**시킨다.

### 2. 랜덤 포레스트 (11/19 보충)
- 결정 트리 하나는 오버피팅되기 쉽다 → 트리를 여러 개 만들어 숲을 이룬다.
- 무작위성이 두 군데 들어간다.
  - **데이터의 다양성** : 트리마다 부트스트랩으로 훈련 데이터를 다르게 뽑는다.
  - **특성의 다양성** : 노드를 나눌 때마다 검토할 특성을 무작위로 고른다. (예 : 30개 중 5개)
- 결합 : 분류는 다수결 또는 클래스별 확률 평균, 회귀는 평균
- `n_estimators` : 트리 개수 / `max_features` : 분할마다 고를 특성 수

## 오늘 배운 것 — 부스팅

### 1. 부스팅이란
- 약한 학습기를 **순차적으로** 학습시키며, 앞 모델이 틀리거나 부족했던 부분을 다음 모델이 보완하게 하는 방법
- 같은 데이터를 쓰되, 다음 모델의 학습 목표나 샘플의 중요도를 바꾼다.

### 2. AdaBoost (Adaptive Boosting)
- 대표적인 초기 부스팅 알고리즘. 주로 깊이 1짜리 트리(**stump**, 그루터기)를 약한 학습기로 쓴다.

**학습 과정**
1. 모든 샘플에 **같은 가중치**를 준다.
2. 반복
   - 현재 샘플 가중치를 반영해 약한 학습기 하나를 학습한다.
   - **가중 오류율**을 계산한다. (틀린 샘플들의 가중치 합)
   - 오류율이 낮을수록 **모델 가중치**를 크게 준다.
   - 틀린 샘플의 **샘플 가중치**를 높인다 → 다음 모델이 그 샘플을 더 중요하게 다룬다.
3. 각 모델의 예측을 모델 가중치로 **가중 투표**해서 최종 클래스를 정한다.

| 가중치 | 묻는 것 |
|---|---|
| 샘플 가중치 | 학습할 때 **어떤 샘플**을 더 중요하게 다룰까? |
| 모델 가중치 | 최종 결합할 때 **어떤 모델의 의견**을 더 크게 들을까? |

**가중 오류율 예**

| 샘플 | A | B | C | D | E | 합 |
|---|---|---|---|---|---|---|
| 가중치 | 0.1 | 0.1 | 0.3 | 0.2 | 0.3 | 1.0 |

| 틀린 샘플 | 일반 오류율 | 가중 오류율 |
|---|---|---|
| A, B | 2 / 5 = 0.4 | 0.1 + 0.1 = **0.2** |
| C, E | 2 / 5 = 0.4 | 0.3 + 0.3 = **0.6** |

- 똑같이 2개를 틀려도, **중요하게 지정한 샘플을 틀리면 더 큰 오류**로 계산된다.
- 이진 분류에서 가중 오류율이 0.5를 넘으면 무작위로 찍는 것보다 못한 모델이다. 그래서 C, E를 틀린 모델은 최종 투표에서 영향력을 얻지 못한다.
- 주의 : AdaBoost는 틀린 샘플에 계속 가중치를 높이기 때문에, **잘못 기록된 데이터나 이상치에 약하다.** 고칠 수 없는 샘플에 점점 더 매달리게 된다.

### 3. Gradient Boosting 계열

| 알고리즘 | 특징 |
|---|---|
| Gradient Boosting (GBM) | 현재 예측의 **손실을 줄이는 방향**으로 다음 학습기를 추가. 제곱오차 회귀에서는 **잔차**를 학습 |
| XGBoost | GBM에 **규제**(모델 복잡도 제어)와 효율적인 계산을 더함. 손실의 1차·2차 미분 정보 활용 |
| LightGBM | 마이크로소프트 개발. **빠른 학습과 메모리 효율**, 대규모 데이터에 유리. 리프 중심 분할 |
| CatBoost | **범주형 특성** 처리에 강함. 범주형 열을 지정하면 내부에서 변환해 인코딩 부담을 줄임 |

#### XGBoost의 학습 과정
1. 초기 예측값을 정한다.
2. 현재 예측의 손실을 줄일 보정값을 계산한다.
3. 그 보정값을 출력하는 새 트리를 학습한다. (이때 리프 수 등 트리의 복잡도를 규제한다 : γ)
4. 새 트리의 출력에 **학습률**을 곱해 기존 예측에 더한다.
5. 반복하며 예측을 조금씩 개선한다.

- 학습률을 곱하는 이유 : 한 번에 다 고치지 않고 **조금씩** 고쳐야 과적합을 줄일 수 있다.

### 4. LightGBM — Leaf-wise vs Level-wise

| | Level-wise (균형 분할) | Leaf-wise (리프 중심 분할) |
|---|---|---|
| 방식 | 같은 깊이의 노드를 **모두** 나눈 뒤 다음 깊이로 | **손실을 가장 많이 줄이는 리프 하나**를 골라 계속 나눔 |
| 모양 | 좌우가 균형 잡힌 트리 | 한쪽으로 깊어지는 비대칭 트리 |
| 장단점 | 안정적이지만 불필요한 분할도 생김 | 같은 리프 수로 손실을 더 줄이지만 **과적합 주의** |
| 예 | XGBoost 기본값 | LightGBM |

- sklearn의 `DecisionTreeClassifier`는 기본적으로 정한 깊이까지 모든 가지를 키운다. `max_leaf_nodes`를 지정하면 손실을 가장 많이 줄이는 리프부터 키우는 방식(leaf-wise)으로 바뀐다.

#### LightGBM의 과적합 방지 파라미터

| 파라미터 | 기본값 | 과적합을 막으려면 |
|---|---|---|
| `num_leaves` | 31 | **줄인다** (트리 하나의 최대 리프 수, leaf-wise라 가장 중요) |
| `max_depth` | −1 (제한 없음) | 값을 정해 깊이를 제한한다 |
| `min_data_in_leaf` | 20 | **늘린다** (리프 하나의 최소 데이터 수) |
| `learning_rate` | 0.1 | 줄이고, 대신 반복 횟수를 늘린다 |
| `bagging_fraction` | 1.0 | 1보다 작게 → 매번 데이터 일부만 사용 |
| `feature_fraction` | 1.0 | 1보다 작게 → 매번 특성 일부만 사용 |
| `lambda_l1`, `lambda_l2` | 0.0 | 키운다 (L1, L2 규제) |
| `num_iterations` | 100 | 너무 크면 오버피팅 (조기 종료와 함께 사용) |
