## 오늘 배운 것

### 1. 조건문
- if-elif는 **순서가 중요하다.**
- `and` = 두 조건이 모두 참

### 2. while문
- **로직이 중요하다.**
- while은 반복 **전**에 조건을 본다. 참이면 반복 실행, 거짓이면 반복 종료
- 디폴트값 0을 설정해 놓아야 한다.
- `count += 1` 문이 없으면 첫 번째 실행부터 무한 반복된다.
- `break`는 해당 조건에서 종료
- `continue`는 해당 조건 건너뛰기

### 3. NumPy는 왜 쓸까?
- 자료구조는 우리가 다룰 데이터를 담을 구조고, 우리는 그 구조를 골라야 한다.
- 넘파이라는 그릇은 넘파이 배열을 쓰겠다는 것이고, 그 이유는 **빠르기 때문**이다. (pandas는 보기가 편하다)
- 숫자 및 과학 연산을 위한 라이브러리. 대규모 다차원 배열을 다룰 수 있게 해 준다.
- 물론 데이터를 수치로 변환해야 한다.
- 버전 확인을 잘 해야 한다.

### 4. NumPy 배열
- 동일한 자료형의 데이터를 하나 이상의 축을 따라 저장하고, 효율적으로 계산할 수 있는 자료구조
- 자료형이 다르게 들어와도 전부 실수형으로 바꿔서 빠르게 계산한다. (자료형 구분 점검하기)
- **벡터화 연산** : 반복문 없이 배열 전체에 대해 연산을 수행한다. 최적화된 루프로 돈다.

```python
import numpy as np
X = np.array([1, 2, 3])
Y = np.array([10, 20, 30])
X + Y   # array([11, 22, 33])  ← 같은 위치끼리 더함

# 리스트였다면
[1, 2, 3] + [10, 20, 30]   # [1, 2, 3, 10, 20, 30]  ← 이어 붙임
```

- `flatten` : 다차원 배열을 1차원으로 펼친다. 순서는 유지된다.
  - 다차원 정보를 각 노드에 입력할 때 펼쳐서 넣는다. (FC 레이어 : Fully Connected Layer)
- `배열명[인덱스] = 변경할 값` : 배열의 값을 바꿀 때 사용

### 5. arange
- `np.arange(시작값, 종료값, 증가값)` : 일정한 간격의 숫자로 넘파이 배열을 생성하는 함수
- 시작값은 생략 시 0, 증가값은 생략 시 1, 종료값은 포함하지 않는다.
- 파이썬 `range`는 정수만 되지만, `np.arange`는 실수 간격도 된다.

```python
np.arange(0, 1, 0.2)        # [0.  0.2 0.4 0.6 0.8]
list(range(0, 1, 0.2))      # TypeError
```

- **게으른 연산** : 동작할 때 값을 하나씩 꺼내 오는 방식. 이래야 메모리 부담이 없다.

### 6. 인덱싱
- **인덱싱** : 인덱스를 지정해 배열의 특정 위치에 있는 원소를 선택하는 것
- 쉼표는 **축 구분**, 콜론은 각 축에서 **선택할 범위**를 지정

```
1    2    3    -> 0행
4    5    6    -> 1행
7    8    9    -> 2행
0열  1열  2열
```

> 너무 신기하다. 행과 열을 이렇게 구분하는구나!
