## 1. 타이타닉 과제 흐름

### 1) 데이터 요약 — describe, info, dtypes

| 자료형 | 뜻 | 타이타닉 열 |
|---|---|---|
| `int64` | 정수 (64비트 칸에 저장) | PassengerId, Survived, Pclass, SibSp, Parch |
| `float64` | 실수 | Age, Fare |
| `object` | 글자(문자열) | Name, Sex, Ticket, Cabin, Embarked |

- **Age가 실수인 이유** : 결측치(NaN)가 있는데, NaN은 실수 타입에만 담을 수 있어서 열 전체가 실수가 된다.
- 결측치 : 891명 중 Age 177개, Cabin 687개, Embarked 2개
- **자료형과 의미는 다를 수 있다.** Survived와 Pclass는 숫자로 저장돼 있지만 성격은 범주다.
  - 구분하는 질문 : "이 값을 다른 글자로 바꿔 적어도 뜻이 같은가?" 그렇다면 범주다.
  - 단, 0과 1로 된 Survived는 평균을 내면 **생존율**이 된다.
- Cabin = 객실 번호 / Embarked = 승선 항구 (S 사우샘프턴, C 셰르부르, Q 퀸스타운)

### 2) 정렬 후 상위 10명

```python
sorted_df = titanic_df.sort_values(by='Fare', ascending=False)  # 1. 줄을 세운다
top10 = sorted_df.iloc[0:10]                                    # 2. 지금 줄의 앞에서 10명
top10.loc[:, ['Name', 'Pclass', 'Fare']]                        # 3. 보고 싶은 열을 고른다
```

- 정렬하면 줄은 다시 서지만 **인덱스(번호표)는 원래 번호를 그대로 들고 있다.**
- 그래서 `loc[0:9]`는 "번호표가 0~9번인 사람", `iloc[0:10]`은 "지금 맨 앞 10명"이다.
- 제출본에서는 정렬 결과를 변수에 담지 않아서, 원래 순서의 앞 10명이 나왔다. **정렬은 결과를 저장해야 남는다.**

### 3) 열 추가 — 1인당 요금

```python
copy_titanic_df = titanic_df.copy()
copy_titanic_df['Fare_per_person'] = copy_titanic_df['Fare'] / (copy_titanic_df['SibSp'] + copy_titanic_df['Parch'] + 1)
```

- `copy`를 통해 원본을 보호한다. `=`만 쓰면 같은 표에 이름표를 하나 더 붙인 것뿐이다.
- 괄호는 아주 중요하다. 괄호가 없으면 `Fare ÷ SibSp`부터 계산된다.
- `=`와 `==`는 다르다. `=`는 할당, `==`는 비교
- 열 이름의 따옴표를 잊지 마라.

### 4) 등급별 생존율 — groupby

```python
titanic_df.groupby('Pclass')['Survived'].mean()
# ( ) 는 묶을 기준 열, [ ] 는 평균 낼 열
```

| 등급 | 생존율 |
|---|---|
| 1등급 | 63% |
| 2등급 | 47% |
| 3등급 | 24% |

- 엑셀의 `AVERAGEIF`와 같은 일을 한다.
- 이 표는 등급과 생존율이 **함께 움직인다**는 것만 보여준다. 등급이 원인인지는 아직 모른다.

## 2. 분석 — 관찰, 가설, 검증, 한계

### 관찰 1 : 성별을 함께 보면

```python
titanic_df.groupby(['Pclass', 'Sex'])['Survived'].mean()   # 기준이 여러 개면 리스트로
```

| 등급 | 여성 | 남성 |
|---|---|---|
| 1등급 | 97% | 37% |
| 2등급 | 92% | 16% |
| 3등급 | 50% | 14% |

- 같은 성별 안에서도 등급 차이가 남는다. 동시에 3등급 여성이 1등급 남성보다 생존율이 높다. 두 요인이 다 크게 작용했다.
- 심슨의 역설 실습과 같은 구조다. 기준을 하나 더 나눠 보면 다른 그림이 보인다.

### 관찰 2 : 나잇대까지 나누면

```python
copy_titanic_df['AgeGroup'] = pd.cut(
    copy_titanic_df['Age'],
    bins=[0, 12, 18, 30, 50, 80],
    labels=['어린이', '청소년', '청년', '중장년', '노년']
)

result = copy_titanic_df.groupby(['Pclass', 'Sex', 'AgeGroup'], observed=True)['Survived'].agg(
    전체='count', 생존='sum', 생존율='mean'
)
result['사망'] = result['전체'] - result['생존']
```

- 그룹이 많아지면 그룹마다 인원이 적어진다. 그래서 **비율만 보지 않고 인원수를 함께 확인했다.**
- `count` = 그 그룹의 인원, `sum` = 생존자 수(0과 1의 합), `mean` = 생존율
- 3등급 객실을 이용한 남성 청년이 매우 많았으며, 그들은 대부분 사망했다.
- 그러나 전원 생존한 어린이를 제외하면, 생존율이 가장 낮은 집단은 **2등급 객실을 이용한 남성**이었다.

### 검증 1 : 어린이와 나이를 모르는 사람을 빼고 남성만 비교

```python
adult_male = copy_titanic_df[
    (copy_titanic_df['Sex'] == 'male')
    & (copy_titanic_df['AgeGroup'] != '어린이')
    & (copy_titanic_df['AgeGroup'].notna())     # NaN도 '어린이가 아님'에 걸리므로 따로 뺀다
]
adult_male.groupby('Pclass')['Survived'].agg(['count', 'sum', 'mean'])
```

| 등급 | 인원 | 생존 | 생존율 |
|---|---|---|---|
| 1등급 | 98 | 37 | 37.8% |
| 2등급 | 90 | 6 | **6.7%** |
| 3등급 | 228 | 29 | 12.7% |

- 결측치를 빼도 "2등급 남성의 생존율이 가장 낮다"는 관찰은 유지됐다.

### 가설 : 가족을 위한 희생이었을까?

```python
adult_male = adult_male.copy()
adult_male['WithFamily'] = (adult_male['SibSp'] + adult_male['Parch']) > 0
adult_male.groupby(['Pclass', 'WithFamily'])['Survived'].agg(['count', 'sum', 'mean'])
```

| 등급 | 혼자 | 가족 동반 |
|---|---|---|
| 1등급 | 37.0% (20/54) | 38.6% (17/44) |
| 2등급 | 7.9% (5/63) | 3.7% (1/27) |
| 3등급 | 14.0% (26/186) | 7.1% (3/42) |

- 가설과 같은 방향의 결과를 찾을 수 있었지만, 표본의 수가 적다는 점에서 추가적인 검토가 필요하다.
- 1등급 객실은 두 경우에 큰 차이가 없었다.
- 2등급과 3등급 객실을 이용한 13세 이상 남성은 가족이 있는 경우 생존율이 절반 정도로 낮았다.
- 이를 통해 상대적으로 낮은 등급의 객실을 이용한, 가족 동승자가 있는 남성이 자신을 희생했다는 해석이 가능해진다.
- 하지만 부모와 형제자매, 자녀 등 다양한 가족 구성원 간의 맥락이 있으므로 희생으로만 단정 지을 수는 없다.

### 한계
- 나이가 누락된 177명은 포함되지 않았다.
- 객실의 위치와 구조, 당시 층별·위치별 상황까지 감안한 해석은 아니다.
- **모든 해석은 생존 여부에서 행동의 동기를 추론한 가설로, 이 데이터만으로는 검증할 수 없다.**

## 3. 에러에서 배운 것

| 에러 | 뜻 | 오늘의 원인 |
|---|---|---|
| `NameError` | 그런 **변수 이름**이 없다 | 셀을 실행하지 않음, 이름 순서가 바뀜(`titanic_df_copy`), 오타(`titanic_dg`) |
| `KeyError` | 변수는 있는데 **그 안에 찾는 열**이 없다 | 이미 지운 열을 또 지우려 함 |
| `SyntaxError` | 문법이 틀렸다 | 쉼표 자리에 마침표 (`'count'. 'sum'`) |
| 축 에러 | 기준 열을 여러 개 넣을 때 | `groupby('Pclass', 'Sex')` → `groupby(['Pclass', 'Sex'])` |

- 파이썬은 **첫 번째 에러에서 멈춘다.** 하나를 고치면 다음 에러가 나온다.
- NameError가 나면 ① 오타와 이름 순서 ② 그 변수를 만든 셀을 실행했는지 확인
- 코랩은 셀의 **마지막 줄 결과만** 보여준다. 중간 결과를 보려면 `print`로 감싸거나 셀을 나눈다.
- 표가 `...`으로 생략될 때 : `pd.set_option('display.max_rows', None)` / 열은 `display.max_columns`

## 4. 그 밖에

### `.str` — 묶음 안의 글자를 다루는 문
- 글자 하나(`"Age"`)에는 `.lower()`를 바로 쓸 수 있지만, 여러 개가 묶인 시리즈에는 바로 못 쓴다. 그때 `.str`을 거친다.

```python
df.columns.str.lower()                    # 열 이름을 모두 소문자로
titanic_df['Name'].str.contains('Mrs')    # 이름에 Mrs가 든 사람을 True/False로
```

- `str(count)`는 숫자를 글자로 바꾸는 함수, `.str`은 묶음 안의 글자를 다루는 문. 이름은 같지만 하는 일이 다르다.
