## 오늘 배운 것

### 1. 데이터 전처리란
- 정제되지 않은 데이터를 **분석·모델링에 적합한 형태로 만드는 과정**이다. 데이터 분석 과정 중 가장 많은 시간이 든다.
- 왜 하나?
  - **정확한 분석 결과** : 불완전한 데이터를 그대로 분석하면 잘못된 결과가 나온다. (Garbage In, Garbage Out)
  - **모델 성능 향상** : 결측치, 이상치, 스케일 차이, 범주형 미처리는 성능 저하와 과적합을 부른다.
  - **현실 반영과 신뢰성** : 현업에서 데이터 품질은 비즈니스의 신뢰성과 직결된다.
- 용어 : **Preprocessing**은 분석 준비 전반, **Cleansing**은 오류·오염 제거 중심, **Refinement**는 가공·정련
- 전처리의 결과물 : **결측치가 없고, 비슷한 스케일의 수치 데이터**

| 용어 | 묻는 것 | 예 |
|---|---|---|
| 무결성 (Integrity) | 값이 정확하고, 변조·손상 없이 유지되는가? | 시험 점수 범위가 0~100인데 A학생이 −1점 |
| 정합성 (Consistency) | 같은 데이터가 서로 모순 없이 일치하는가? | id 1이 한 곳에서는 "김럭스", 다른 곳에서는 "김로보" |
| 품질 (Quality) | 분석 목적에 쓸 만한가? | |

- 무결성을 지키는 방법 중 하나가 **입력 검증**(입력 데이터의 유효성 검증)이다.

### 2. 데이터를 보는 네 가지 관점

| 관점 | 묻는 것 | 구분 |
|---|---|---|
| 데이터의 구조적 유형 | 데이터가 어떻게 구성되어 있는가? | 정형, 반정형, 비정형 |
| 변수 유형 | 값이 무엇을 의미하는가? | 범주형, 수치형 |
| 변수 역할 | 모델링에서 어떻게 쓰이는가? | 입력변수 X, 목표변수 y |
| 데이터 타입(자료형) | 프로그램이 값을 어떻게 다루는가? | int, float, str, bool |

- 변수 유형은 더 나뉜다.
  - 범주형(질적) : **명목형**(성별, 혈액형), **순서형**(만족도, grade)
  - 수치형(양적) : **이산형**(인원, 방문 수), **연속형**(신장, 체중)
- 데이터 구조의 차원 : 2차원은 Table, Array, DataFrame / 3차원은 이미지(가로, 세로 + **채널** 정보)
- 데이터 분류에 따라 처리 기법이 달라지므로 유의해야 한다.

### 3. 데이터 분할

```python
X = iris.data      # 입력 (feature, columns, 요인, 독립변수)
y = iris.target    # 정답 (target, label, output, 종속변수)

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
```

| 데이터 | 역할 | 보통 비율 |
|---|---|---|
| Train | 모델을 학습시킨다 (모델 파라미터를 업데이트) | 60 ~ 80% |
| Validation | 학습한 모델의 성능을 평가하고 **하이퍼파라미터를 조정**한다. 과적합을 막는다 | 10 ~ 20% |
| Test | 훈련·검증에 쓰지 않은 데이터로 **최종 성능**(일반화 성능)을 평가한다 | 10 ~ 20% |

- **모델 파라미터** : 학습 과정에서 데이터로부터 자동으로 정해지는 값 (예 : 가중치)
- **하이퍼파라미터** : 분석가가 직접 설정하는 모델 설정값
- 3분할 예시 (70 / 15 / 15) : 먼저 `test_size=0.3`으로 나누고, 남은 30%를 `test_size=0.5`로 다시 반씩 나눈다.
- **교차 검증(Cross-Validation)** : 데이터를 여러 번 나누어 학습과 검증을 반복해, 성능을 더 안정적이고 신뢰성 있게 평가하는 방법

### 4. 결측치 처리
- **결측치** : 데이터에 값이 없는 것. 수집 과정의 오류나 실수로 생긴다.

| 하고 싶은 일 | 방법 |
|---|---|
| 개수 확인 | `info()`의 Non-Null 개수, `isna().sum()` |
| 위치 확인 | `isna()`, `notnull()`, `sns.heatmap(df.isna())` |
| 다른 값으로 대체 | `df['Age'].fillna(df['Age'].mean())` |
| 제거 | `dropna()` |

- `isna()`와 `isnull()`은 같은 함수다. NaN은 판다스의 결측치 표기다.
- 평균으로 대체하면 결측치인 칸만 평균이 되고, 나머지는 원래 값이 유지된다.

```python
df.dropna(axis=0)                  # 결측치가 하나라도 있는 행 제거
df.dropna(subset=['Age'], axis=0)  # 특정 열(Age)에 결측치가 있는 행만 제거
df.dropna(axis=1)                  # 결측치가 있는 열 제거
```

### 5. 이상치와 극단치

| | 이상치 (Anomaly) | 극단치 (Outlier) |
|---|---|---|
| 뜻 | 값의 범위에서 많이 벗어난 값. 수집 과정의 오류가 동반된다 | 극단적으로 크거나 작은 값 (존재할 확률이 매우 낮다) |
| 예 | 체온 20도 또는 50도, 3022년도 신입생, 330점 | 키 2m 30cm |
| 처리 | 결측치처럼 제거나 대체 | 분석·모델링에 영향을 주므로 제거하기도 한다 |

- **이상치 확인** : `value_counts()` 뒤 `sort_index()`로 정렬해서 위아래 끝을 본다. 범위를 벗어난 값은 `np.where`로 NaN으로 바꿀 수 있다.
- **극단치 확인** : 통계적 기준을 쓴다.
  - **IQR** : Q1 − 1.5 × IQR 미만, Q3 + 1.5 × IQR 초과
  - **Z-score** : 절댓값이 3을 넘는 값
- 박스플롯의 IQR 기준은 정규분포로는 **±2.698σ** 바깥에 해당한다.

```python
Q1 = df['score'].quantile(0.25)
Q3 = df['score'].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = df[(df['score'] < lower) | (df['score'] > upper)]     # 극단치 확인
cleaned  = df[(df['score'] >= lower) & (df['score'] <= upper)]   # 극단치 제거
```

### 6. 데이터 변환
- **`to_numeric`** : 숫자형으로 바꾼다. 바꿀 수 없는 값을 `errors` 옵션으로 다룬다.

| errors | 바꿀 수 없는 값은 |
|---|---|
| `'ignore'` | 원본 그대로 둔다 |
| `'coerce'` | 지우고 NaN으로 바꾼다 |
| `'raise'` | 오류를 내고 코드를 멈춘다 |

- **`astype`** : 원하는 자료형으로 바꾼다. `df['열'].astype('변경할 자료형')`
- 문자형을 숫자로 : 성별 `female`은 0, `male`은 1로 바꿔 `gender` 열을 만든다.
- 문자형을 명목 변수로 : 승객의 호칭(Mr, Mrs, Miss)에 특별한 지위(Master, Don, Rev)를 `Special`로 묶어 4개 값을 가진 `title` 열을 만든다.
- 두 열을 합쳐 새 열을 만든 것이 **파생변수**다.

### 7. 원-핫 인코딩
- **원-핫 인코딩** : 범주형 데이터를 모델이 처리할 수 있도록 **0과 1의 이진 벡터**로 바꾸는 기법

```
"사과"   → [1, 0, 0]
"바나나" → [0, 1, 0]
"체리"   → [0, 0, 1]
```

```python
pd.get_dummies(df['category_column'])
```

| | 내용 |
|---|---|
| 장점 | 범주 간 **거리가 동일**해져 모델이 특정 범주에 치우치지 않는다. 모델이 데이터를 처리하기 쉽다 |
| 단점 | 범주가 많으면 변수가 크게 늘어(**차원의 저주**) 복잡도와 과적합 위험이 커진다. 대부분이 0인 **희소 행렬**이 생겨 메모리와 계산이 비효율적이다 |

- 필요한 모델은 수치형 모델이다. (선형 모델, SVM, 신경망, 군집화)
