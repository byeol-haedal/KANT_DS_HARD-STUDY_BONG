## 오늘 배운 것

### 1. 회귀 모델의 종류
- **ML의 회귀** : 입력 변수의 정보로 **수치형 목표값을 예측**하는 과제 (이름의 유래는 11/19 TIL)

| 구분 | 모델 | 예측 방식 |
|---|---|---|
| 선형 회귀 | `LinearRegression` | 입력 특성의 **가중합 + 절편** |
| 단일 트리 회귀 | `DecisionTreeRegressor` | 조건에 따라 입력 공간을 나누고, 각 영역의 평균값 |
| 앙상블 회귀 | `RandomForestRegressor`, `GradientBoostingRegressor` | 여러 트리의 예측을 평균하거나 순차적으로 보완 |
| 신경망 회귀 | `MLPRegressor` | 은닉층에서 관계를 학습하고 출력층에서 수치값 예측 |

- **로지스틱 회귀**는 이름에 "회귀"가 있지만 **분류 모델**이다. (아래 5번)

### 2. 공분산 → 상관 → 회귀

| 구분 | 묻는 것 | 결과 |
|---|---|---|
| 분산 | 하나의 변수는 얼마나 퍼져 있는가? | 개별 변수의 변동 |
| 공분산 / 상관 | 두 변수는 어떤 방향으로, 얼마나 함께 변하는가? | 상관계수 (−1 ~ 1) |
| 회귀 | 그 관계를 식으로 표현해 Y를 예측할 수 있는가? | 회귀식, 회귀계수, 예측값 |

- 상관계수는 **관계의 강도와 방향**, 회귀계수는 **X가 한 단위 변할 때 Y가 얼마나 변하는가**를 말한다.
  - 예 : 가격 = 1 + 0.05 × 면적 − 0.02 × 연식 → 면적이 1 늘면 가격이 0.05 오르고, 연식이 1 늘면 0.02 내린다.
- 상관이나 회귀 결과만으로 **인과관계를 단정할 수는 없다.**

### 3. 선형 회귀와 결정계수(R²)
- 선형 회귀는 데이터로부터 **오차가 가장 적은 회귀선**을 찾는다. (최소제곱법)

```python
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X, y)   # 오차가 작아지는 계수와 절편을 학습
```

| 제곱합 | 무엇과 무엇의 차이 | 뜻 |
|---|---|---|
| SST (총제곱합) | 실제값 ↔ 평균 | 데이터 전체의 퍼짐 |
| SSR (회귀제곱합) | 예측값 ↔ 평균 | 모델이 **설명한** 변동 |
| SSE (오차제곱합) | 실제값 ↔ 예측값 | 모델이 **설명하지 못한** 변동 |

```
SST = SSR + SSE
R² = SSR / SST = 1 − SSE / SST
```

- **R²** : 종속변수의 전체 변동 중 모델이 설명하는 비율. 보통 0 ~ 1이고, 1에 가까울수록 설명력이 높다.
  - R² = 1 : 모든 예측이 실제값과 일치 / R² = 0 : 평균으로 예측한 것과 같다 / **R² < 0** : 평균으로 예측하는 것보다 못하다
  - R² = 0.5가 좋은지 나쁜지는 분야와 데이터에 따라 다르게 해석된다.

#### 연습 문제 풀이

| | 실제값 | 예측값 | (실제 − 평균)² | (예측 − 평균)² | (실제 − 예측)² |
|---|---|---|---|---|---|
| 1 | 4 | 3 | 1 | 4 | 1 |
| 2 | 3 | 4 | 4 | 1 | 1 |
| 3 | 5 | 6 | 0 | 1 | 1 |
| 4 | 8 | 7 | 9 | 4 | 1 |
| 합 | 평균 5 | | **SST = 14** | **SSR = 10** | **SSE = 4** |

- 14 = 10 + 4로 SST = SSR + SSE가 성립한다.
- R² = 10 / 14 ≈ **0.71** → 전체 변동의 약 71%를 모델이 설명한다.

### 4. 단순 회귀, 다중 회귀, 다항 회귀

| | 식 | 입력 |
|---|---|---|
| 단순 선형 회귀 | y = w₁x₁ + b | 1개 → 직선 |
| 다중 선형 회귀 | y = w₁x₁ + w₂x₂ + w₃x₃ + b | 여러 개 → 평면, 초평면 |
| 다항 회귀 | y = b + w₁x + w₂x² | 입력을 제곱 등으로 확장 |

- 입력이 많아져도 **각 특성의 가중합으로만 예측하면 여전히 선형 모델**이다.
- **다항 회귀도 선형 모델이다.** "선형"은 학습하는 계수 w에 대해 선형이라는 뜻이라서, x² 같은 항을 넣어도 계수는 그대로 더해진다. 그래서 `LinearRegression`으로 곡선을 그릴 수 있다.
  - 단, 제곱항은 분석가가 직접 만들어야 한다. 모델이 알아서 찾아 추가하지 않는다.
- 비선형 관계의 예 : 온도가 적정 수준까지는 생산량이 늘다가 넘으면 줄어드는 곡선, 광고비 효과가 할인율에 따라 달라지는 상호작용, 특정 온도를 넘으면 불량률이 급증하는 임계점

### 5. 로지스틱 회귀 (Logistic Regression)

| | 선형 회귀 | 로지스틱 회귀 |
|---|---|---|
| 목적 | 연속값 예측 (가격, 매출) | **이진 분류** (예/아니오, 0/1) |
| 출력 | 연속값 | **확률 (0 ~ 1)** |
| 학습 기준 | MSE 최소화 | 로그 손실(교차 엔트로피) 최소화 |

#### 확률 → 오즈 → 로그오즈
- **오즈(odds)** = p / (1 − p) : 성공 확률과 실패 확률의 비율. p = 0.8이면 오즈 = 4, "성공이 실패보다 4배 유리"
- **로그오즈(log-odds)** = log(p / (1 − p))

| 확률 p | 오즈 | 로그오즈 |
|---|---|---|
| 0.01 | 약 0.0101 | 약 −4.595 |
| 0.20 | 0.25 | 약 −1.386 |
| 0.50 | 1 | 0 |
| 0.80 | 4 | 약 1.386 |
| 0.99 | 99 | 약 4.595 |

- 왜 로그를 쓰나? 확률은 0 ~ 1, 오즈는 0 ~ ∞로 범위가 갇혀 있다. 로그를 씌우면 **−∞ ~ +∞** 가 되어 직선(선형식)으로 다루기 쉬워진다.
- 로그오즈가 0이면 확률 50%, 양수면 50%보다 크고, 음수면 50%보다 작다.

#### 로지스틱 회귀가 예측하는 순서
1. 입력으로 **선형 점수** 계산 : z = b₀ + b₁x
2. 이 점수를 **로그오즈**로 본다 : z = ln(p / (1 − p))
3. **시그모이드** 함수로 확률로 바꾼다 : p = 1 / (1 + e⁻ᶻ)
4. **임계값**(보통 0.5)을 적용해 클래스를 정한다

- **시그모이드 함수** : 어떤 값이든 0 ~ 1 사이로 바꾸는 S자 곡선
  - z가 커지면 1에, 작아지면 0에 가까워지고, **z = 0이면 0.5**다. 이 지점이 **결정 경계**다.

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))
```

#### 예 : 타이타닉 생존 예측
- 계수(예시) : b₀ = −4, b₁(Age) = −0.05, b₂(Fare) = +0.04 — 학습을 통해 업데이트된다.
- 승객 A (나이 20, 요금 80)
  - z = −4 + (−0.05 × 20) + (0.04 × 80) = **−1.8**
  - p = σ(−1.8) ≈ **0.142**
  - 0.142 < 0.5 → 예측 : 0 (사망)

#### 왜 분류에 선형 회귀를 쓰지 않나
- 선형 회귀는 직선이라 예측값이 0 ~ 1을 벗어나 확률로 해석하기 어렵다.
- 공부 시간과 합격(0/1) 예시에서, 공부 시간이 아주 긴 데이터 (20, 1)를 하나 추가하자 직선이 크게 기울면서 **분류 경계가 6에서 10으로 밀려났다.** 극단값 하나에 경계가 흔들린다.
- 시그모이드는 출력을 0 ~ 1로 묶어 두기 때문에 이런 문제를 줄인다.

### 6. 실습 결과 읽기 — 타이타닉 로지스틱 회귀
- 데이터의 생존 비율 : 사망 61.6%, 생존 38.4%

| 실제 ↓ / 예측 → | 예측 0 | 예측 1 |
|---|---|---|
| 실제 0 | 93 (TN) | 17 (FP) |
| 실제 1 | 19 (FN) | 50 (TP) |

- **Accuracy = (93 + 50) / 179 ≈ 0.80**
  - 이 숫자만 보면 안 된다. 모두 "사망"이라고만 찍어도 약 62%가 나온다. 그래서 **기준선(BaseLine, 다수 클래스)** 과 비교해야 한다.

| Positive 기준 | Precision | Recall | F1 |
|---|---|---|---|
| 사망 (0) | 93 / 112 ≈ 0.83 | 93 / 110 ≈ 0.85 | 약 0.84 |
| 생존 (1) | 50 / 67 ≈ 0.75 | 50 / 69 ≈ 0.72 | 약 0.74 |

- **macro avg ≈ 0.79** : 클래스 수만 고려 (불균형 무시) / **weighted avg ≈ 0.80** : 표본 수(110 vs 69) 반영
- 어떤 클래스를 Positive로 보느냐에 따라 정밀도·재현율이 달라진다.
