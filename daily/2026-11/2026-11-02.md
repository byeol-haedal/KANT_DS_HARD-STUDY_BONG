## 오늘 배운 것

### 1. 상관성과 과적합
- 상관성이 더 강조된다. 인과성의 규명이라는 것은 간단하지 않다.
- 물론 앞으로도 그 상관성이 계속 유지될지는 알 수 없기 때문에 예의주시해야 한다.
- 진짜 성능을 검증하기 위해 학습 데이터를 전부 쓰지 않는다. 전부 쓰게 되면 그저 답을 외우게 된다.
- 모델 성능은 모델이 복잡해지면 좋아지지만, 그렇지 못한 지점도 있다. 그것이 **과적합**이다.
- 너무 훈련 세팅에만 적합화되어 현장에서는 쓸 수 없다. 그래서 과적합 대응이 중요하다.

### 2. 라이브러리
- **라이브러리** : 자주 사용되는 코드나 함수, 클래스 등을 미리 만들어 모아 둔 자원의 집합
- **무엇이 어디 있는지 아는 것(know where)** 이 중요하다. 잘 찾아서 갖다 쓰자.
- 생산성 : 직접 짜고 있느니 라이브러리에서 갖다 쓰고, 더 중요한 지점에서 고민하자.

| 종류 | 쓰는 법 |
|---|---|
| 내장 함수 | 바로 쓸 수 있다 (`print`, `len`, `sorted`, `abs`, `max`, `pow`) |
| 표준 라이브러리 | `import`를 따로 해야 한다 |
| 외부 라이브러리 | 추가 설치(`!pip install`)를 해야 한다 |
| 사용자 정의 함수 | 직접 작성한다 |

- `import` = 불러온다. import한 것은 메모리에 올라간다. 다 불러오면 편하지만 용량과 시간이 드니 필요할 때만 불러온다.
- `!pip`의 `!` : 파이썬 문법이 아니라 "이 줄을 운영체제의 셸 명령으로 실행해 달라"는 표시

### 3. 함수

```python
def f(x):              # def : 함수를 정의하는 키워드 / f : 함수 이름 / x : 매개변수
    result = 2 * x + 1 # 함수가 하는 일
    return result      # 결과 반환

answer = f(3)          # 인자 3을 전달해 함수 실행
print(answer)          # 7
```

- **매개변수(parameter)** : 함수를 정의할 때 외부에서 들어올 값을 위해 미리 만들어 두는 빈자리 (`x`, `name`)
- **인수·인자(argument)** : 함수를 호출할 때 실제로 넣는 값 (`3`, `"봉주!"`)
- 함수 이름은 보통 하는 일을 동사로 짓는다. `greet` = 인사하다, `get_area` = 넓이를 구하다

```python
def greet(name):
    print("Hello," + name)

greet("봉주!")   # Hello,봉주!
```

### 4. 객체
- 일상 세계의 객체를 컴퓨터가 이해할 수 있도록 메모리 공간에 구현해 놓은 데이터의 묶음
- 객체의 '상태'는 변수(데이터)로, '행동'은 함수(메서드)로 조립해 하나의 묶음으로 만든다.
  - **속성** : 객체가 가지고 있는 데이터
  - **메서드** : 객체가 할 수 있는 기능. `emp_ids.append(...)`처럼 점(.) 뒤에 붙는다.
- **객체(인스턴스)** : 클래스에 따라 만들어져 실제로 사용하는 대상

## 실습에서 알게 된 것

### 1. `range`는 숫자 목록이 아니라 규칙이다

```python
print(range(1, 10))         # range(1, 10)  ← 숫자가 아니라 규칙이 그대로 출력
print(list(range(1, 10)))   # [1, 2, 3, 4, 5, 6, 7, 8, 9]  ← list()로 펼쳐야 보인다
```

- 끝 값은 포함되지 않는다. `range(1, 10)`은 1부터 9까지
- `range`는 **정수만** 받는다.

```python
print(list(range("T001", "T011")))
# TypeError: 'str' object cannot be interpreted as an integer
```

### 2. 귀찮은 반복은 코드로 줄인다 — T001 ~ T010 만들기

```python
# 풀어 쓴 방식 : 빈 리스트 → 반복 → 하나씩 추가
emp_ids = []
for i in range(1, 11):
    emp_ids.append("T" + str(i).zfill(3))

# 한 줄 방식 : 리스트 컴프리헨션 + f-문자열
emp_ids = [f"T{i:03d}" for i in range(1, 11)]
```

- `emp_ids = []` : 비어 있는 상자를 먼저 만든다
- `for` : 하나씩 꺼내서, 그때마다 들여쓴 내용을 반복한다
- `append` : 리스트 맨 뒤에 하나 추가한다
- `zfill(3)` / `:03d` : 3자리로 맞추고 빈자리는 0으로 채운다

**직접 응용** : 학생 30명 번호 만들기

```python
std_ids = []
for i in range(1, 31):
    std_ids.append("학생" + str(i).zfill(2))

print(len(std_ids))   # 30
print(std_ids[-1])    # 학생30   ← [-1]은 맨 뒤에서 첫 번째
```

### 3. 에러 없이 지나갔는데 나중에 터지는 경우

```python
%%writefile calculator.py
def add(a, b)          # ← 콜론(:)이 빠졌는데도 에러 없이 저장됨
    return a + b
```

```python
import calculator
# SyntaxError: expected ':' (calculator.py, line 1)
```

```python
import importlib, calculator
importlib.reload(calculator)   # 고친 파일을 다시 읽으라고 알려준다
print(calculator.add(3, 4))    # 7
```

- `%%writefile`은 코드를 파일에 쓰기만 해서, 문법 오류는 import하거나 실행할 때 드러난다.
- **Traceback은 맨 아래부터 읽는다.** 파일 이름, 줄 번호, `^` 위치를 확인한다.
- 에러가 연달아 나면 **맨 처음 실패한 셀부터** 의심한다. (오늘은 `%%writerfile` 오타)
