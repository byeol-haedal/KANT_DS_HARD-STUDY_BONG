## 오늘 배운 것 — SVM

### 1. SVM (Support Vector Machine)이란
- 두 클래스를 나누는 경계 중에서, **양쪽 데이터로부터 가능한 한 여유 있게 떨어진 경계**를 찾는 지도 학습 모델

| 용어 | 뜻 |
|---|---|
| 결정 경계 (decision boundary) | 서로 다른 클래스를 나누는 경계 |
| 초평면 (hyperplane) | 결정 경계를 일반화한 말. 2차원에서는 선, 3차원에서는 평면, N차원에서는 N−1차원 |
| 서포트 벡터 (support vector) | 결정 경계와 **가장 가까운** 데이터. 경계를 정하는 데 직접 영향을 준다 |
| 마진 (margin) | 결정 경계 양쪽에 확보하는 여유 폭 |

- 경계는 **서포트 벡터라는 일부 데이터만으로** 정해진다. 경계에서 먼 데이터는 움직여도 경계가 바뀌지 않는다.

### 2. 결정 경계를 식으로 쓰면

```
wᵀx + b = 0      ← 경계 위의 점
wᵀx + b > 0      ← 경계 한쪽 (예 : 합격)
wᵀx + b < 0      ← 경계 다른 쪽 (예 : 불합격)
```

- **w** : 경계에 수직인 가중치 벡터. 경계의 **방향**을 정한다.
- **b** : 편향. 경계의 **위치**를 옮긴다.
- **x** : 입력 데이터 하나의 특성 벡터
- 예 : 경계를 x₂ = x₁로 잡으면 w₁ = −1, w₂ = 1, b = 0
  - 공부 시간 2, 점수 5인 학생 A (2, 5)는 x₂ > x₁ → 경계 위쪽
  - (5, 2)는 아래쪽, (3, 3)은 경계 위에 있다.
- SVM의 학습은 **마진을 가장 크게 만드는 w와 b를 찾는 것**이다.
  1. 임의의 결정 경계에서 시작한다.
  2. 마진을 크게 확보하면서, 마진을 침범하거나 잘못 분류된 데이터에 대한 벌점은 줄이도록 경계를 조정한다.
  3. 최종 경계가 정해지면, 그 경계를 결정한 데이터가 서포트 벡터가 된다.

### 3. 하드 마진 vs 소프트 마진

| | 하드 마진 | 소프트 마진 |
|---|---|---|
| 규칙 | 모든 데이터가 마진 바깥에 있어야 한다 | 일부 데이터가 마진을 침범하거나 잘못 분류되는 것을 허용한다 |
| 오차 | 허용하지 않는다 | 허용하면서도 마진은 최대한 넓게 |
| 위험 | 훈련 데이터에 **과적합** | 새 데이터에 더 잘 일반화된다 |

- 마진의 폭 ρ = 2 / ‖w‖ → w의 크기를 줄일수록 마진이 넓어진다.

### 4. 커널 함수와 커널 트릭
- **선형 SVM의 한계** : 한 클래스가 가운데 모여 있고 다른 클래스가 그 주변을 고리처럼 둘러싸면, 직선 하나로는 나눌 수 없다.
- **해결 1 — 특성 변환** : 새 특성을 만들어 차원을 올린다.
  - 예 : z = x₁² + x₂² (원점에서의 거리의 제곱)를 추가하면, 가운데 모인 점은 z가 작고 바깥 점은 z가 크다. 3차원에서는 **평면 하나로** 나눌 수 있다.
  - 원래 공간에서 원 모양(비선형)이던 경계가, 변환된 공간에서는 평면(선형)이 된다.
  - 단, 고차원 특성을 실제로 만들면 계산 부담이 크다.
- **해결 2 — 커널 트릭** : 새 특성을 직접 만들지 않고, 고차원에서 계산한 것과 같은 결과(두 데이터의 **내적**)를 **커널 함수**로 바로 계산한다.

| | 특성 변환 | 커널 트릭 |
|---|---|---|
| 새 특성 | 직접 만든다 | 만들지 않는다 |
| 계산 | 변환된 특성으로 학습 | 커널 함수로 변환 공간의 내적만 계산 |

### 5. 실습 — 타이타닉 SVM
- 데이터 로드와 전처리 → 특성 선택과 인코딩 → 데이터 분할 → 학습과 예측 → 평가 (정확도, 혼동 행렬, F1)

## 오늘 배운 것 — 군집화

### 1. 군집화 (Clustering)
- **정답(레이블)이 없는** 데이터를 비슷한 특성끼리 자동으로 묶는 **비지도 학습**
- 데이터를 공간에 놓았을 때 **거리가 가까우면 같은 군집**, 멀면 다른 군집으로 본다.
- 2개로 묶을지, 3개로 묶을지는 정해져 있지 않다. 이것을 정하는 게 군집화의 큰 문제다.
- 활용 : 소비 패턴에 따라 고객 유형 나누기, 비슷한 토픽끼리 뉴스 기사 묶기

### 2. K-Means의 과정
1. **K** : 클러스터 개수를 사용자가 정한다.
2. **Centroid** : 클러스터의 중심점 K개를 정한다.
3. 각 데이터를 **가장 가까운 중심점의 클러스터**에 배정한다.
4. 배정된 데이터로 **중심점을 다시 계산**한다. (클러스터 안 데이터의 평균 위치)
5. 중심점이 더 이상 바뀌지 않을 때까지 3, 4를 반복한다.

- KNN(11/19)과 이름에 K가 같이 들어가지만 다르다.

| | KNN | K-Means |
|---|---|---|
| 학습 방식 | 지도 학습 (정답 있음) | 비지도 학습 (정답 없음) |
| 하는 일 | 새 데이터를 분류 | 데이터를 군집으로 묶음 |
| K의 뜻 | 참고할 이웃의 수 | 만들 군집의 수 |

### 3. K-Means의 두 가지 고민

#### 1) K를 몇으로 할까 — 엘보우, 실루엣
- **엘보우 방법 (Elbow Method)**
  - **이너셔(Inertia)** : 각 데이터와 자기 클러스터 중심점 사이 거리의 제곱합. 작을수록 데이터가 중심에 촘촘히 모여 있다(응집도가 높다).
  - K를 늘리면 이너셔는 계속 줄어든다. 그래서 가장 작은 값이 아니라, **줄어드는 속도가 갑자기 꺾이는 지점(팔꿈치)** 을 K로 고른다.
- **실루엣 점수 (Silhouette Score)** : 데이터 하나마다 계산한다.
  - **a** = 같은 클러스터 안의 다른 데이터들과의 평균 거리 (가까울수록 좋다)
  - **b** = 가장 가까운 **다른** 클러스터의 데이터들과의 평균 거리 (멀수록 좋다)
  - 실루엣 = (b − a) / max(a, b)
  - 모든 데이터의 실루엣을 평균 내고, **평균이 1에 가장 가까운 K**를 고른다.

| 실루엣 값 | 뜻 |
|---|---|
| 1에 가까움 | 자기 군집에 가깝고 다른 군집과 멀다 → 잘 분리됨 |
| 0에 가까움 | 두 군집과의 거리가 비슷하다 → 경계에 걸쳐 있음 |
| 음수 | 다른 군집에 더 가깝다 → 잘못 배정됐을 가능성 |

- 실루엣은 데이터가 많을수록 계산 시간이 늘어난다.

#### 2) 시작 중심점을 어디에 둘까 — Random, K-means++

| | Random | K-means++ |
|---|---|---|
| 방법 | 중심점을 무작위로 고른다 | 첫 중심점만 무작위, 이후는 **기존 중심점에서 먼 데이터일수록** 뽑힐 확률을 높인다 |
| 장단점 | 간단하고 빠르지만 결과가 불안정할 수 있다 | 중심점이 서로 떨어져 시작해 결과가 더 안정적이다 |

```python
kmeans = KMeans(n_clusters=3, init='k-means++', random_state=42)   # 기본값
kmeans = KMeans(n_clusters=3, init='random', random_state=42)
```
