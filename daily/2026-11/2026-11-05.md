## 오늘 배운 것 — Pandas

### 1. 데이터 분석 파이프라인
- 판다스로 기본적인 데이터 분석도 가능하다.
- **데이터 분석 파이프라인** : 데이터(raw data)를 소스로부터 수집하여, 변환 및 적재를 거쳐 분석이나 ML 학습에 활용할 수 있는 상태로 만드는 자동화된 데이터 이동 및 처리 흐름

```
데이터 소스 → 수집 → 처리 · 변환 → 저장 → 분석 · 모델링
```

- 데이터를 불러오는 방법
  - 로컬에 따로 있는 파일을 불러오기
  - 파이썬에 내장된 실습용 데이터(아이리스 등)를 코드로 불러오기
  - 판다스에서는 웹에 있는 데이터를 URL로 불러올 예정
- 전처리, EDA를 하고 저장하면, 개별 모델이 이를 받아 학습한 뒤 결과가 나온다. 최종적으로 릴리스한다.
- A라는 소스가 들어와 목적지까지 가고, B도 마찬가지로 흘러가야 한다. 처리·변환에서 자연스럽게 쭉 이어져야 하고, 다른 모델에도 쭉 흘러가야 한다.
- 완전 자동화는 물론 안 된다. 사람의 개입은 필요하지만, 개념(코드)상 결과까지 도출되어야 한다.
- **파이프라인이라는 키워드 안에서 설명할 수 있어야 한다.**

### 2. 시리즈와 데이터프레임
- 표로 만들면 핸들링하기 쉽다.
- **시리즈** = 열 하나 (1차원)
- **데이터프레임(df)** = 행과 열로 구성된 2차원 표
  - index = 이름, data = 내용
  - **열** = 변수 = 특성
  - **행** = 관측치, 샘플
- 리스트 → `pd.Series`로 변환할 수 있다. 문자열도 가능하다.
- `head()`는 위에서, `tail()`은 아래에서 불러온다. (기본 5개)
- 데이터를 잘 골라내는 것도 중요하다. 행렬 연산이 많이 이루어진다.

### 3. 데이터를 불러왔다면 먼저 확인할 것
- **데이터가 제대로 불러와졌는지** 확인해야 한다.
- **비율 확인은 늘 해야 한다.** (불균형 기준 3:7)
  - 생존 여부처럼 0과 1로 된 열은 `len`으로 전체 수를, `sum`으로 생존자 수를 알 수 있다.
- null과 공백은 다르다.
- 도메인과 비즈니스에 대한 이해를 가지고, 몇 개의 주요한 변수로 추론해야 한다.
  - 예 : Pclass(객실 등급)는 생존에 영향을 주는가?

### 4. 카테고리형
- 판다스의 데이터형에 카테고리형이 있는 이유는? **별도의 연산 효율**이 있기 때문이다.
- 그냥 불러와서 데이터프레임에 담아도 동작은 하지만, 성별처럼 몇 가지 값만 반복되는 열은 카테고리형으로 형변환하면 효율이 좋아진다.
- 설계라는 측면에서 최적화하는 것이다.

### 5. describe 함수

| 항목 | 의미 |
|---|---|
| count | 데이터 개수 |
| mean | 평균 |
| std | 표준편차 |
| min | 최솟값 |
| 25% | 1사분위수 (작은 값부터 줄 세웠을 때 25% 위치) |
| 50% | 2사분위수 = 중앙값 |
| 75% | 3사분위수 (작은 값부터 줄 세웠을 때 75% 위치) |
| max | 최댓값 |

### 6. 인덱스, loc과 iloc
- **인덱스** : 데이터를 식별하고 선택하기 위해 행 또는 열에 붙이는 라벨
- **loc** (location) : **라벨(이름)** 로 찾아간다.
- **iloc** (integer location) : **정수 위치(몇 번째)** 로 찾아간다.

### 7. groupby
- 판다스에서는 `groupby`로 그룹을 짓는다. 지역별, 제품별, 나이, 형제자매 수, 성별 등
- SQL의 GROUP BY와 차이는? 개념적으로는 같고 표현식이 다르다.
- 각 그룹별로 다른 모습을 보일 수 있다.

### 8. 문자열 공백 제거
- `strip()` : 양쪽 공백 제거
- `lstrip()` : 왼쪽(left) 공백 제거
- `rstrip()` : 오른쪽(right) 공백 제거

## 오늘 들은 것 — AI 개론

### 1. 인공지능
- **AI** : Artificial Intelligence
- **튜링 테스트** : 컴퓨터와 사람을 구별할 수 있는가?
- 인공지능은 1940년대에 시작해 세 번의 굴곡이 있었다. 중간에 퍼셉트론으로 다시 주목을 받았다.

### 2. 퍼셉트론 — 뉴런을 모방한 것 (ANN)

| 생물의 뉴런 | 인공 신경망 |
|---|---|
| 수상돌기 (신호를 받음) | 입력값 x |
| 시냅스 (연결의 세기) | 가중치 w |
| 세포체 (신호를 모음) | 가중합 Σ |
| 축삭돌기 (신호를 내보냄) | 출력값 (y 예측값) |

- 이 형식이 곧 **퍼셉트론**이다.
- 퍼셉트론 하나로는 풀지 못하는 문제가 있었는데, **다층 퍼셉트론**이 등장한다. 은닉층을 여러 층 쌓아서 풀 수 없던 분류 문제를 풀 수 있게 한다. 이것이 딥러닝의 시작이 된다.

### 3. 학습의 흐름
- **순전파** : X → Y로 예측값을 계산한다.
- **손실함수** : 정답과 예측값의 차이를 잰다. 정답이 50인데 예측값이 37이면 차이는 13.
- **역전파** : 그 13의 차이에 각 가중치가 얼마나 영향을 줬는지 **미분**으로 거꾸로 추적한다.
- **경사하강법** : 그 결과를 보고 오차가 줄어드는 방향으로 가중치를 조금씩 고친다. 이를 수백, 수천 번 반복해 최적의 가중치를 찾는다.
- **미분** : 평균 변화율의 간격을 아주 좁히면, 그 순간의 변화율(기울기)이 된다.
- 95%만 나와도 잘 나왔다고 생각한다.

### 4. CNN — 이미지 분석에 강한 딥러닝 모델
- 예 : 128×128 이미지를 4×4 **필터**라는 돋보기로 훑으며 학습한다.
- **제로 패딩** : 가장자리도 충분히 보기 위해 이미지 테두리를 0으로 둘러 넓힌다.
- **맥스 풀링** : 구역마다 가장 큰 값만 뽑아서 저장한다.
- **flatten** : 쌓인 2차원 결과를 한 줄로 펼친다. 여기서 하나하나의 값이 노드가 된다.
- CNN은 전처리 과정에서 행렬을 다룰 수 있어야 한다.

### 5. 비지도학습 — 오토인코더
- 인코더에서 노드가 줄어들며 정보를 압축하고, 디코더에서 노드가 다시 늘어나며 처음 넣은 데이터를 복원한다.
- 정답 레이블 없이 입력 자체를 복원하는 방식이라 비지도학습에 속한다.

### 6. 그 밖에
- 도서관 비유 : 모듈이나 패키지는 책을 넣은 꾸러미이고, 그 안의 책 한 권 한 권이 함수(메서드)다.
- **GPT** : Generative Pre-trained Transformer. 광범위하게 사전 학습된 트랜스포머
