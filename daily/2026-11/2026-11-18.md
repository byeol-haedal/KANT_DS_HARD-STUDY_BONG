## 오늘 배운 것

### 1. 모델 학습이란
- 질문 : 키(y)와 몸무게(X) 데이터를 가장 잘 설명하는 **직선 하나**는?
  - `y = b0 + b1·X`에서 데이터를 설명할 수 있는 b0, b1 값은 여러 개다. 그중 가장 잘 맞는 값을 찾는 것이 학습이다.
- **f : X → Y** : 입력 X에서 출력 Y로 가는 함수 F를 **근사(approximate)** 하는 과정
  - 입력 X에 대해 예측값 **Ŷ = F(X)** 가 실제 정답 Y와 최대한 비슷해지도록 F를 학습한다.
  - 즉, X를 사용해 Y를 예측한다.

| 기호 | 뜻 | 예 (집값 예측) |
|---|---|---|
| X (특성, feature) | 모델에 전달되는 데이터 | 집의 크기, 방의 개수, 위치 |
| F (모델) | 입력을 받아 결과를 돌려주는 예측 규칙 | |
| Ŷ = F(X) (예측값) | X가 F를 통과해 나온 결과 | 예측한 집값 |

- **완벽한 함수는 찾기 어렵다.** 현실의 문제는 매우 복잡해서 X와 Y 사이의 정확한 수식을 알 수 없다.
  - 그래서 학습은 수많은 (X, Y) 쌍을 관찰해, 정답 Y와 가장 비슷한 Ŷ을 만드는 **최적의 F를 찾는 근사 과정**이다.
  - 예측이 얼마나 빗나갔는지는 잔차(Ŷ − Y)로 보고, 잔차를 모두 모은 것이 **SSE**다. SSE는 모델로 설명할 수 없는 부분이다.
- 정리하면, 학습은 독립변수와 종속변수의 관계를 가장 잘 설명하는 **파라미터의 최적값(optimal values of the parameters)** 을 찾는 것이다.

### 2. 학습 방식에 따른 분류 — 정답이 있는가

| | 지도 학습 | 비지도 학습 |
|---|---|---|
| 데이터 | 문제와 **정답(Label)** 이 함께 있다 | 정답이 없다 |
| 방식 | 정답을 보며 X → Y를 학습 | 모델 스스로 데이터 속의 규칙을 찾는다 |
| 목표 | 출력값 예측 및 분류 | 숨겨진 패턴과 구조 발견 |

- 번역도 지도 학습이다. '오늘은 금요일입니다'와 'Today is Friday'라는 짝을 보고 X → Y를 학습한다.

### 3. 목표(Task)에 따른 분류 — 무엇을 예측하는가

| | 분류 (Classification) | 회귀 (Regression) |
|---|---|---|
| 목표변수 y | 범주형 (클래스) | 연속형 (수치) |
| 질문 | 이 데이터는 **어느 그룹**에 속하는가? | 이 데이터의 **값은 얼마**인가? |
| 비유 | 객관식 문제 | 주관식 문제 |
| 예 | 아이리스 꽃 종류, 손글씨 숫자(MNIST), 사진 속 대상(CIFAR), 영화 리뷰 감정 | 내일의 기온, 아파트 가격, 캘리포니아 주택 가격 |

- **GPT도 분류 모델이다.** 앞의 문맥을 보고 다음에 올 토큰 후보들의 확률을 계산한다(다중 클래스 분류). 고른 토큰을 문맥에 붙이고 예측을 반복해서 문장을 만든다.
  - 예 : "나는 아침에" 다음은 밥을 45%, 커피를 30%, 운동을 15%
- **일대다(One-vs-Rest) 분류** : 다중 클래스 문제를 여러 개의 이진 분류로 바꿔 푼다. 한 번에 한 클래스만 양성으로, 나머지는 모두 음성으로 보고 분류기를 훈련한다. 기본적으로 이진 분류만 하는 모델에서 유용하다.
- 분류와 회귀를 **둘 다** 할 수 있는 모델 : Decision Tree, Random Forest, SVM, 인공 신경망
- 그 밖의 Task : 랭킹·추천, 시계열 예측, 이상탐지
- **명확한 목표 설정이 중요하다.** 문제 정의 → 목표 설정 → 모델 선택

### 4. 회귀 문제와 오버피팅
- 회귀 문제 : 기존 데이터로 학습한 뒤, 새로운 데이터의 결과값을 예측한다.
  - 데이터로부터 **오차가 가장 적은 회귀선**을 계산하고, 새 몸무게가 들어오면 그 선으로 키를 예측한다.
- 모든 점을 하나도 빠짐없이 지나가는 구불구불한 선은 정답일까?
  - 아니다. 학습 데이터에만 지나치게 맞춘 **오버피팅(과적합)** 이다. 새로운 데이터에서는 오히려 예측을 잘 못한다.
