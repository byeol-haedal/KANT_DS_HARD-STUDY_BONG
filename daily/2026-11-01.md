## 주제
**<점프 투 파이썬> 예제 따라 하기** — 조건문(if)과 반복문(for)

<br>

## 오늘 한 것
- 책에 나와 있는 예제들을 무작정 따라 해 봤다.
- 오타와 실수로 잔뜩 오류가 났지만, 코랩을 통해 수정 사항을 확인했다.

### 1. 잘 돌아간 코드

```python
if 4 in [1, 2, 3, 4]: print("4가 있습니다")
# 4가 있습니다
```

### 2. 오류가 난 코드 → 코랩 Gemini로 수정해 출력

```python
language = ['python', 'perl', 'c', 'java']

for lang in language:
    if lang in ['python', 'perl']:
        print("%6s need interpreter" % lang)
    elif lang in ['c', 'java']:
        print("%6s need compiler" % lang)
    else:
        print("should not reach here")
```

```
python need interpreter
  perl need interpreter
     c need compiler
  java need compiler
```

### 3. 내가 낸 오류들

| 내가 쓴 것 | 고친 것 | 이유 |
|---|---|---|
| `for lang in languages;` | `for lang in language:` | `for`, `if` 같은 제어문 끝에는 세미콜론(`;`)이 아니라 콜론(`:`) |
| `languages` | `language` | 첫 줄에서 만든 변수 이름과 한 글자라도 다르면 다른 변수로 본다 |
| `print(:"should not reach here")` | `print("should not reach here")` | 괄호 안에 불필요한 콜론 |
| `"6%s"` | `"%6s"` | `%6s` = 문자열을 6칸 너비에 오른쪽 정렬. 순서가 바뀌면 다른 뜻 |
